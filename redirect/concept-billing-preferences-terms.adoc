= Termini e definizioni
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Le preferenze di fatturazione controllano il modo in cui NetApp Console gestisce i pagamenti, le fatture e il comportamento di rinnovo per le tue licenze e i tuoi abbonamenti.  È possibile impostare le preferenze a uno dei due livelli:

* *Globale*: si applica a licenze dirette, abbonamenti al marketplace e abbonamenti Keystone .
* *Per abbonamento* — si applica solo a un marketplace specifico o a un contratto di licenza diretta.


La fonte di fatturazione può essere la seguente:

* *Abbonamenti Marketplace* — La fatturazione avviene tramite AWS Marketplace, Azure Marketplace o Google Cloud Marketplace.  Puoi scegliere l'account di fatturazione, la regione e le opzioni di rinnovo fornite dal cloud marketplace.
* *Licenze dirette* — La fatturazione avviene tramite NetApp.  Nella NetApp Console puoi gestire le chiavi di licenza, i contatti per le fatture e il rinnovo automatico.
* * Abbonamenti Keystone * — La fatturazione avviene tramite il contratto Keystone .  Nella NetApp Console puoi gestire i destinatari delle fatture e i tag dei centri di costo.




== Permessi

Per modificare le preferenze di fatturazione è necessario disporre del ruolo di *Account Admin* o *Billing Admin*. Gli operatori possono visualizzare le preferenze ma non possono modificarle.



== Imposta le preferenze di fatturazione

Le preferenze di fatturazione consentono di: - applicare un unico elenco di contatti per le fatture in tutti i servizi, - allineare l'utilizzo ai centri di costo, - gestire le notifiche di rinnovo automatico e scadenza, - garantire che i nuovi sistemi Cloud Volumes ONTAP (CVO) ereditino l'account di fatturazione corretto.



= Campi di fatturazione



== Campi del Marketplace

* *Marketplace provider* — AWS, Azure o Google Cloud.
* *Billing account / subscription ID* — L'account di fatturazione cloud da utilizzare per l'addebito.
* *Durata del contratto* — Durata e modalità di rinnovo.




= Opzioni e definizioni di fatturazione



== Termini e opzioni

* **NetApp licenses first** — Fatturazione a fronte di licenze NetApp attive. L'utilizzo aggiuntivo viene trasferito sul marketplace.
* **Solo abbonamenti al Marketplace** — Tutto l'utilizzo viene fatturato tramite contratti del marketplace.
* **PAYGO (Pay-As-You-Go)** — Abbonamento flessibile con fatturazione in base all'utilizzo effettivo.
* **Contratto annuale** — Abbonamento a tempo determinato al marketplace.
* **Rinnovo automatico** — Rinnova il contratto automaticamente alla scadenza.
* **Configurazione CVO personalizzata** — Modalità avanzata per la mappatura di più abbonamenti per cloud provider.
* **Licenza diretta** — licenza gestita da NetApp utilizzata prima della capacità del marketplace.
* **Hyperscaler** — AWS, Azure o cloud provider Google.
* **Finestra di dialogo Conferma modifiche** — Appare prima dell'applicazione degli aggiornamenti per evitare modifiche accidentali alla fatturazione.




== Percorsi di configurazione tipici

| Scenario | Opzione di fatturazione consigliata | |-----------|-----------------------------| | Utilizzo della capacità acquistata NetApp | Prima le licenze NetApp | | Utilizzo solo di contratti del marketplace | Solo abbonamenti del marketplace | | Fatturazione di più progetti con un unico cloud provider | Abilita configurazione CVO personalizzata | | Ripristino della fatturazione predefinita | Disabilita configurazione CVO personalizzata |
